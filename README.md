# ConnectWave 공식 웹사이트 클론 프로젝트

## 프로젝트 한 줄 요약

커넥트웨이브(ConnectWave) 공식 웹사이트를 클론 구현한 프로젝트로,  
**GSAP 애니메이션**을 활용해 스크롤 흐름에 따른 콘텐츠 전환과  
시각적 몰입도를 표현했습니다.

## 배운 점 / 인사이트

### GSAP을 활용한 스크롤 기반 애니메이션 구현

GSAP과 ScrollTrigger를 사용해  
스크롤 위치에 따라 요소가 등장하고 전환되도록 구현하며,  
**애니메이션 타이밍과 화면 흐름의 관계**를 이해할 수 있었습니다.

### 애니메이션 중심 UI 흐름 설계 경험

단순한 효과 추가가 아닌,  
콘텐츠 전달 순서에 맞춰 애니메이션을 배치하며  
**사용자 시선 흐름을 고려한 화면 구성**의 중요성을 경험했습니다.
