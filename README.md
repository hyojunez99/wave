# MotionFit (Airbnb Style Clone)

## 한 줄 요약
운동 공간 예약 서비스를 가정해 Airbnb 스타일의 메인 페이지를 HTML과 CSS로 디자인 중심으로 구현한 클론 프로젝트입니다.

---

## 진행 기간
- 개인 프로젝트  
- 2025.10.23 ~ 2025.10.27 (4일)

---

## 프로젝트 개요
본 프로젝트는 실제 서비스의 기능 구현보다는 화면 구성과 레이아웃 설계에 집중한 UI 클론 프로젝트입니다.  
HTML과 CSS를 사용해 메인 페이지의 구조와 디자인을 중심으로 구현했습니다.

---

## 주요 내용

### 메인 페이지 UI 디자인
- 실제 서비스 메인 화면을 참고해 전체 레이아웃과 시각적 요소를 구성

### 반응형 레이아웃 구성
- 데스크탑과 모바일 환경에 따라 레이아웃이 자연스럽게 변경되도록 구현

### 카드 기반 화면 구성
- 반복되는 카드 UI를 활용해 콘텐츠가 정리되어 보이도록 레이아웃 설계

### 헤더 및 푸터 디자인
- 실제 서비스 구조를 참고해 정보성 중심의 헤더와 푸터 영역 구성

---

## 기술 스택

### Frontend
- HTML5
- CSS3

---

## 배운 점

- 기능 구현 없이도 HTML과 CSS만으로 서비스 화면의 전체 구조와 디자인을 표현할 수 있다는 것을 경험했습니다.
- 반응형 레이아웃을 구성하며 화면 크기에 따른 콘텐츠 배치와 우선순위를 고민할 수 있었습니다.
- 마크업 구조를 어떻게 설계하느냐에 따라 CSS 작업 효율과 유지보수성이 달라진다는 점을 이해하게 되었습니다.
